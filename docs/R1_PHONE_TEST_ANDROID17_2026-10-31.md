# Android17 实机低风险测试记录

日期：2026-10-31，时区 Asia/Shanghai。用户授权通过哪吒 MCP 测试手机，并明确禁止高危测试。

## 目标与边界

- 节点 31“手机”，Android17 / SDK37 / ARM64，QTI SM8750，Adreno 830。
- 当前版本 `2.1.0+android.A0.11.0-r1`，测试 App 进程名对应 `com.nezhahq.agent.r1test`。
- 用户提供的 Root 环境为 SukiSU；实际 `id -u` 返回 0。只读父链观察到 App UID10545 与其启动的 UID0 shell/helper，确认当前 Root 执行可用；未读取管理器配置或修改授权。
- 测试仅使用短命令、少量公开系统文件读取和面板状态查询。没有写入/删除手机文件，没有修改配置或权限，没有重启、挂载、安装、网络变更、压力负载或其他状态变更操作。
- 当前连接中只有这一台 Android 节点，未测试 Android15 设备。
